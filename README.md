One sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3). The program writes that sentence to `/output/entry.txt` — no code, no explanation, the sentence is the whole entry.

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
